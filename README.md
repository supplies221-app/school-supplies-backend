# سيرفر تطبيق الأدوات المدرسية — خطوات النشر (من غير كتابة كود)

## أولاً: الفرق بين ده وبين النسخة التجريبية اللي جربناها
النسخة اللي جربتها في المحادثة كانت بتشتغل بحيلة خاصة بمنصة Claude من غير مفتاح API حقيقي.
السيرفر ده مختلف: بيستخدم **مفتاح Anthropic API حقيقي**، وده معناه:
- لازم تعمل حساب على https://console.anthropic.com
- تضيف بطاقة دفع (الاستخدام بيتحاسب على عدد الصور اللي بتتحلل - تكلفة صغيرة جداً لكل صورة، مش تكلفة ثابتة شهرية)
- هتاخد "API Key" من هناك وتحطه في مكانه (هنوضح فين)

هنا التطبيق بقى **حقيقي وجاهز للنشر**، مش مجرد تجربة.

---

## الخطوات

### 1) اعمل حساب GitHub (لو مش عندك)
- روح https://github.com وسجل حساب مجاني
- اعمل Repository جديد (زرار "New")، سميه مثلاً `school-supplies-backend`
- ارفع الملفات دي كلها جواه (server.js, catalog.json, package.json, .env.example):
  - من صفحة الـ Repository، دوس "Add file" → "Upload files"
  - اسحب الملفات وارفعها، ودوس "Commit changes"

### 2) اعمل حساب على Render (استضافة مجانية)
- روح https://render.com وسجل حساب مجاني (تقدر تسجل بحساب GitHub مباشرة)
- دوس "New" → "Web Service"
- اختار الـ Repository اللي رفعته في الخطوة اللي فاتت
- في الإعدادات:
  - **Build Command:** `npm install`
  - **Start Command:** `npm start`
  - **Instance Type:** اختار الخطة المجانية (Free)

### 3) ضيف مفتاح Anthropic
- في نفس صفحة إعدادات Render، دور على قسم **Environment Variables**
- ضيف متغير باسم `ANTHROPIC_API_KEY` وقيمته المفتاح اللي أخدته من console.anthropic.com

### 4) اضغط Deploy
- Render هيثبت الملفات ويشغل السيرفر تلقائياً
- بعد ما يخلص، هتلاقي لينك عام زي: `https://school-supplies-backend.onrender.com`
- ده هو اللينك اللي التطبيق (اللي هنبنيه في FlutterFlow) هيكلمه

### 5) جرّب إن السيرفر شغال
افتح اللينك في المتصفح، المفروض تشوف:
```
School Supplies API is running ✅
```

## الـ Endpoints المتاحة (اللي التطبيق هيكلمها)

**POST /analyze** — بترسل صورة، بترجع الأصناف المستخرجة
```json
{ "imageBase64": "...", "mediaType": "image/jpeg" }
```

**POST /price** — بترسل الأصناف + المستوى، بترجع الأسعار والإجمالي
```json
{ "items": [{"item":"كراسة","quantity":3}], "tier": "economic" }
```
